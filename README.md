# Python lab 3

---

## Условие задачи

### Задание

Реализовать декоратор `timed_logged`, который логирует вызовы функций: имя функции, документацию, аргументы, результат (или информацию об исключении) и время выполнения. Декоратор должен корректно работать с функциями, принимающими произвольные позиционные и именованные аргументы, сохранять имя и документацию обёрнутой функции, а также пробрасывать исключения после их логирования.

---

## Описание решения

В файле `timed_log.py` реализован декоратор `timed_logged`, который:

- Замеряет время выполнения функции с помощью `time.perf_counter()`.
- Логирует:
  - имя функции (`func.__name__`),
  - документацию (`func.__doc__`),
  - позиционные и именованные аргументы (`args`, `kwargs`),
  - результат выполнения (при успехе) или тип и сообщение исключения (при ошибке),
  - время выполнения в миллисекундах с точностью до трёх знаков.
- Использует `functools.wraps` для сохранения метаданных обёрнутой функции.
- Пробрасывает исключение дальше после логирования (`raise`).

В конце файла приведены два теста:

1. `slow_sum` — функция с задержкой, возвращающая сумму двух чисел.
2. `divide` — функция целочисленного деления, вызываемая с нулевым делителем для проверки логирования исключения.

## Запуск программы

Для выполнения задания не нужны виртуальное окружение и дополнительные пакеты —
достаточно установленного Python 3.

### 1. Клонируйте репозиторий и перейдите в папку задания

Скопируйте и выполните команды в терминале:

```bash
git clone https://github.com/cinq-sur-cinq/task-1-timed-log.git
cd task-1-timed-log
```

### 2. Запустите программу

```bash
python timed_log.py
```

Если команда `python` в вашей системе ссылается на Python 2 или не найдена,
используйте:

```bash
python3 timed_log.py
```

После запуска программа выведет информацию о вызовах функций `slow_sum` и `divide`,
включая время выполнения и сообщение об исключении `ZeroDivisionError`.
